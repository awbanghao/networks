This repository contains analysis scripts, data files, and output objects related to the NSHAP network analysis project conducted on March 24, 2026. 

File Descriptions:

1. Files_BootstrapBEI_240326.RData - Nonparametric bootstrap results for BEI values.
2. Files_BootstrapCaseDrop_2402326.RData - Case-dropping bootstrap results for BEI values.
3. Files_BootstrapEdge_2402326.RData - Nonparametric bootstrap results for edge weights.
4. Files_Codebook_140226.pdf - Codebook describing NSHAP variables and values.
5. Files_Dataset_240326.xlsx - NSHAP dataset.
6. Files_ImputedData_240326.RData - Imputed dataset.
7. Files_Network_240326.RData - Network object.
8. Files_Network_240326.pdf - Network plot.
9. Files_Predictability_240326.csv - Nodewise predictability values.
10. Files_RawData_240326.RData - Dataset as object.
11. Files_Script_240326.Rmd - RStudio script.
12. Files_Script_240326.html - R knitted file.
13. Files_Simulation_240326.RData — Network simulation object.
14. Files_Styles_240326.css - Style sheet for knitted file.
15. Networks_Final_230326.docx - Final report.
16. Networks_Final_230326.pdf - Final Report (as pdf).
17. Output_BridgeValues_240326.csv - Raw BEI values.
18. Output_EdgeWeights_240326.csv - Raw edge weights.
19. Output_Predictability_240326.csv - Nodewise predictability values.
20. README.md - Instructions.
21. video1.pdf - Plot for presentation (simple network plot).
22. video2.pdf - Plot for presentation (BEI values plot).
   

Usage:
1. Open Files_Script_240326.Rmd in RStudio.
2. Ensure all required .RData files are loaded into the working directory (same folder as analysis script).
3. Knit or run the R Markdown file to replicate the full analysis and generate visual outputs.
